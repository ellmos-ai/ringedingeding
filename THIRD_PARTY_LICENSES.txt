Why it is vendored rather than loaded from a CDN: the web interface has to work
with no network at all, because the dry run is the default mode of this program
and a page that needs the internet to render would contradict that. Vendoring
also means there is no build step, no package manager and no third-party host
involved in serving it.

Runtime dependencies (not bundled, installed by pip)
--------------------------------------------------------------------------
The command line has none.

The optional [web] extra pulls in FastAPI (MIT), Starlette (BSD-3-Clause),
uvicorn (BSD-3-Clause), Jinja2 (BSD-3-Clause) and python-multipart (Apache-2.0).
These are installed by the package manager and are not part of this repository.
